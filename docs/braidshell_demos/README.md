## 🚀 Try It Yourself

Run BraidShell:

```bash
cd /home/ubuntu/RSE/src/cpp_kernel
./braidshell
```

Available commands:
- `info` - System information
- `torus` - Torus visualization
- `perf` - Performance metrics
- `matrix` - Enter the matrix (animation)
- `help` - Show all commands
- `clear` - Clear screen
- `exit` - Exit BraidShell
